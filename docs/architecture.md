# 架构总览

## 一、设计理念

RoboClaw 是一个专门为**人形机器人**设计的垂直领域 Agent 框架。它的核心设计理念是：

1. **语言优先**（Language-First）：用户通过自然语言下达任务，Agent 自动分解为可执行的子任务
2. **感知-行动闭环**：Perceive → Reflect → Plan → Act → Feedback 的完整循环
3. **跨形态对齐**：同一套任务规划逻辑可适配不同机器人形态（Unitree H1、Agility Digit 等）
4. **安全第一**：实时安全监控 + 多层次故障恢复，最后防线永远是请求人类帮助

## 三、技术栈详解

| 组件 | 技术选型 | 用途 |
|------|---------|------|
| **编排引擎** | LangGraph StateGraph | 构建 Agent 主循环，管理状态流转与条件路由 |
| **状态管理** | LangGraph PostgresSaver | 状态检查点持久化，支持故障恢复 |
| **API 层** | FastAPI + WebSocket + SSE | REST API + 实时遥测推送 |
| **数据模型** | Pydantic v2 | 全量数据校验与序列化 |
| **LLM 集成** | LangChain | 任务分解、工具调用 |
| **工作记忆** | Redis Hash (TTL) | 短时状态缓存、事件环形缓冲 |
| **情景记忆** | PostgreSQL (asyncpg) | 历史任务执行记录、全文搜索 |
| **语义记忆** | Milvus (向量数据库) | 相似任务检索、技能匹配、故障模式 |
| **空间记忆** | 内存度量-语义地图 | 房间拓扑、物体位置、可导航性 |
| **知识库** | PostgreSQL | 结构化领域知识（物体可供性、安全规则） |
| **消息队列** | RabbitMQ | 传感器事件、任务事件、A2A 通知 |
| **机器人通信** | ROS 2 (规划中) | 关节指令、传感器话题、Action 服务 |

## 五、关键设计模式

### 5.1 责任链恢复 (Chain of Responsibility)
故障恢复采用优先级链模式：SelfDiagnose → RePlan → RetrySkill → SafeStop → HumanHelp。
HumanHelp 永远是链中最后一个策略，`can_handle()` 始终返回 `True`，确保恢复链永远不会陷入死胡同。

### 5.2 上下文编译器 (Context Compiler)
规划不是凭空进行的。`ContextCompiler` 承担桥梁角色，在生成 LLM 提示词前从五种记忆层级中采集相关数据：
- **工作记忆** → 当前机器人状态
- **情景记忆** → 过去相似任务的历史记录
- **语义记忆** → 向量检索相似情景和技能
- **空间记忆** → 当前房间、物体位置
- **知识库** → 物体可供性、安全规则

### 5.3 SubTask DAG
任务分解不生成线性序列，而是一个有向无环图（DAG）。每个子任务声明前置条件（依赖的子任务 ID），`TaskGraph.next_executable()` 返回所有前置条件已满足的子任务。这天然支持并行执行。

### 5.4 内存回退 (Graceful Degradation)
所有记忆模块都有两套实现：
- **生产模式**：Redis / PostgreSQL / Milvus 真后端
- **开发模式**：进程内 dict 回退
当基础设施不可用时，框架自动降级到内存模式，不会崩溃。

### 5.5 人形特定状态
`HumanoidState` 继承 `RobotState`，增加了双足机器人特有的状态字段：
- ZMP（零力矩点）、CoP（压力中心）
- 左右脚接触状态、支撑相
- 双机械臂分别的姿态和力传感器
- 头部云台角度

## 六、配置体系

```
configs/
├── default.yaml          # 全局默认配置
└── robots/
    ├── h1_unitree.yaml   # Unitree H1 形态配置
    └── digit_v3.yaml     # Agility Digit 形态配置
```

每个机器人配置文件包含：
- **embodiment**: 关节数量、手指数量、身高、体重、关节限位
- **safety**: ZMP 支撑多边形、力阈值、急停减速度
- **skills**: 默认技能参数（抓取策略、行走速度、臂工作空间半径）
